## 0. 设计原则（一页纸）

**5 条原则，决定后续所有具体决策**：

1. **沿用察元已有视觉**：`brand=#3D7BFF`、卡片 16/20 圆角、ink 黑色 pill、iris 紫蓝渐变、emoji + 浅色底块的图标方块——**不另起设计语言**。
2. **Coze 借走"应用商店心智"**：市场首页用大卡 + 分类 SegmentedTabs（已落地 SpacePage，沿用）；不学 Coze 的厚顶栏。
3. **Dify 借走"工作台心智"**：左中右三栏 Studio（导航 + 画布 + 配置面板）；不学 Dify 的蓝绿色饱和度。
4. **Notion 借走"草稿/发布"心智**：编辑永远走 draft、`Publish` 是显式动作、顶栏显示 `正在编辑：草稿（基于 v1.2.0）`——**让用户知道自己在改的是什么**。
5. **Linear 借走"快速键 + Tasklist"心智**：`Cmd-K` 是一等公民，待办用清单视图、不用看板（私有化场景重路径效率而非协作仪式）。

**反 8 条**（明确不做的事）：

- 不做 Dify 的"App Type 大色块图标墙"——视觉太杂
- 不做 Coze 的"Bot 头像 + 大字描述"占满首屏——浪费纵向空间
- 不做拖拽排序的 Sidebar——固定 IA，认知负担小
- 不做花哨的 onboarding 引导墙——hover/empty state 内置教学即可
- 不做"全平台暗色"——跟随系统主题（已有 token 支持）
- 不做模态嵌套——Drawer + Inline panel 替代
- 不做 emoji + Ant Design 那种"过度节日感"
- 不做表单的实时校验弹气泡——只在 blur / submit 时校验

### 2.4 字号 / 间距 / 圆角

- 字号：`xs 12 / sm 14 / base 16 / lg 18 / xl 20 / 2xl 24`（现有 token）

- 圆角：卡片 `xl=16` / 弹窗 `2xl=20` / Composer `3xl=24` / pill `full`
- 阴影：仅 hover 用 `0 1px 3px rgba(0,0,0,0.04)`，不滥用

| 场景 | 时长 | 缓动 |

| 节点拖拽 | follow | -- |
| 时间线展开 | 240ms | `ease-out` |
| Toast 进出 | 180ms | `ease-out` |

## 4. 通用交互模式（覆盖所有屏幕）

### 4.1 加载 / 空 / 错误 状态规范

| 形态 | 何时 | 视觉 |
| --- | --- | --- |
| **首屏 skeleton** | < 200ms 不显示;>200ms 显示 skeleton | 卡片占位 + shimmer |
| **加载更多** | 列表底部 spinner | 24px circular |
| **空** | 列表无数据 | hero illustration + 一句指引 + 一个 CTA 按钮 |
| **错误** | 5xx / 网络错 | 居中 illustration + 一句话原因 + "重试"按钮 |
| **离线** | 检测到离线 | 顶部黄色 banner "离线模式,将使用上次缓存" |

### 4.2 Toast / Confirm 规范

- **Toast** 右下角，最多堆 3 条；3s 自动消失；带 action（"撤销"）
- **Confirm** 居中模态，二选一 + 副标题描述后果（不要纯 Yes/No）
- **危险动作**（删除、覆盖、unpublish）：模态主按钮红色，需键入应用名确认

### 4.3 快捷键（Cmd 键 = Linear 心智）

| 键 | 全局 | Studio | Tasklist |
| --- | --- | --- | --- |
| `Cmd-K` | CMD-K 调色板 | 同 | 同 |
| `Cmd-S` | -- | 保存草稿 | -- |
| `Cmd-Enter` | -- | 调试运行 | 表单提交 |
| `Cmd-Shift-P` | -- | 发布 | -- |
| `g, s` | 进 Space | -- | -- |
| `g, t` | 进 Tasklist | -- | -- |
| `?` | 显示快捷键帮助 | 同 | 同 |

### 4.4 实时性

- **Tasklist** 用 WebSocket 单连接（`/ws/notifications`），新任务即时插入
- **DebugPanel** 用 SSE 跟随 run
- **协作**（M8.5）：Studio 顶栏右上角"当前编辑者:lily 30s 前"，30s 心跳

### 4.5 主题

- 跟随系统：`prefers-color-scheme`；设置里有"亮 / 暗 / 跟随"切换
- 暗色专门校对：节点底色饱和度 -20%、border 亮度 +30%
