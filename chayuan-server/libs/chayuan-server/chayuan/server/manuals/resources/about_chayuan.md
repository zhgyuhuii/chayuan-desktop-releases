## 一句话介绍

**察元 AI（Chayuan）** 是一款装在本地电脑上的办公 AI 助手：打开 WPS / Word 文档，它能**逐字逐词**帮你审错别字、核对引用、规范公文表述；同时把文档库、数据库、向量库、办公私库、图像五类知识源统一成一个问答入口。

对话、文本嵌入、重排、语音识别、图像嵌入、OCR 六类能力**全部在本机跑**，密钥和文档**永不出域**。全量版安装包断网即可跑通全部功能，并适配麒麟 / UOS / openKylin 等国产操作系统与国产 CPU。

## 它能帮你做什么

### 1. 字词级文档审核

打开 WPS / Word 文档，察元逐字逐词高亮问题，鼠标悬停就出改写建议 —— 比普通拼写检查更深，接近一位资深公文编辑：

- **错别字 / 形近字 / 同音字** 三档检测；
- **引用核查** —— 政策文件、法律法规、标准号自动比对，过期或失效会标红；
- **公文规范** —— 口语化表述、模糊表态、违规承诺、敏感词自动识别；
- **一键采纳** —— 替换 / 插入批注 / 链接批注三种写回方式，不接受不留痕。

### 2. 察元智库 —— 五类知识源统一查询

一个入口问全部知识，每条答案都带引用和诊断：

| 前缀 | 知识源 | 例子 |
|---|---|---|
| `doc:` | 文档库 | PDF / Word / Excel / Markdown / HTML / 图像 |
| `src:` | 结构化数据源 | MySQL / PostgreSQL / Oracle / 达梦 / 金仓 / Doris |
| `vec:` | 外部向量库 | Milvus / Chroma / Zilliz / PGVector / Relyt |
| `office:` | 办公私库 | 企业 / 团队 / 个人三层私域 |
| `img:` | 图像库 | CLIP 图像向量，以图搜图 / 以文搜图 |

结构化数据问题（"有几个客户""上季度销售额"）走 Text2SQL + 只读 AST 校验，不会退化成文档检索瞎答。

### 3. 六类能力，全部本地

全量版安装包内置全部 6 类推理模型，断网即可跑通对话、检索、转写、OCR、图像理解全链路：

| 能力 | 模型 | 体积 |
|---|---|---|
| 对话 | Qwen3-4B-Instruct（GGUF）+ llama.cpp | 1.85 GB |
| 文本嵌入 | gte-multilingual-base（mGTE，8192 token 长上下文） | 300 MB |
| 重排 | bge-reranker-v2-m3 | 600 MB |
| 语音识别 | whisper.cpp tiny（可升级 base / medium） | 74 MB |
| 图像嵌入 | CLIP ViT-B/32 + infinity sidecar | 605 MB |
| OCR | RapidOCR PP-OCRv4（ONNX 三件套） | 16 MB |

任一能力都可在界面 / 命令行切换默认模型，业务侧零修改、下次请求即生效。

### 4. Model Arena 多模型对抗 + 30+ 工具

- **Model Arena**：一个对话页面排 N 个泳道，统一发送，横向对比不同模型的生成质量；
- **30+ 内置工具**：Text2SQL（17 种 SQL 方言）、Web 搜索、图像生成、钉钉 / 飞书 / GitHub / arXiv 等开箱即用；
- **MCP 协议**：既做客户端也做服务端；
- **Folder Sync**：本地文件夹自动构建文档知识结构，引用一键回链原文。

## 隐私 · 离线 · 数据落地

所有数据都在本机、在你自己选的目录里：

| 路径 | 内容 |
|---|---|
| `<CHAYUAN_ROOT>/data/` | 聊天历史、知识库元数据、向量索引 |
| `<CHAYUAN_ROOT>/models/` | 本地模型权重 |
| `<CHAYUAN_ROOT>/manuals/` | 用户手册（本文档所在） |

- 删账号不丢历史；
- 断网状态下对话 / 检索 / 转写 / OCR 全链路可用；
- **唯一例外**：你主动选用云端模型时，对应那次的 prompt 才会发往该模型厂商。
